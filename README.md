# Home Assistant Operations

## What this is:
* Infrastructure-as-code, Docker Compose definitions, and operations tooling for local Home Assistant deployment.

## Why it was written:
* To maintain reproducible configuration, container lifecycle scripts, and backup automation for smart home services.

## Where it is deployed:
* Runs locally via Docker / Docker Compose on the host machine.
* Config directory: `/home/trentdouthat/projects/home_assistant_ops/config/`
* Web interface accessed via `http://localhost:8123` (or local network IP).
